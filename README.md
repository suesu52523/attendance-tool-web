一、本分支改了什么
1. **整改执行定位改为「业务键」**：从「按 ID（系统序号）定位」改为「**工号 + 原开始日期 + 原开始时间**」定位，ID 仅作回退。
2. **不再静默失败**：未定位 / 多条命中 / 无法识别的处置方式，统一进「定位异常清单」，页面可见、可下载。
3. **防重复执行**：「确认执行」加了三道守卫（本轮已执行过 / 未导入整改表 / 存在未填写处置方式 → 都不执行）。
4. **异常匹配**：姓名不再参与定位（只做"姓名不一致"提醒）；同人同日多条标「多条命中」并列出候选（含班组）。
5. **导入校验加强**：新增「重复填报检测」；整行空白跳过；`25:70`、`24:00` 等越界时间拦截；日期正则加锚点。
6. **处置方式识别**：自由文本（"删除加班""已改"…）进「未识别」清单，不再静默忽略。
7. **导出保护**：没有数据时不再导出内置示例数据。
